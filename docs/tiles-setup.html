Step 2 — Convert GeoJSON → PMTiles Current Step
Install tippecanoe and convert each GeoJSON layer to a .pmtiles file with correct zoom bounds.
Install tippecanoe: brew install tippecanoe
Convert hex-grid.geojson → hex-grid.pmtiles (Z2–z10)
Convert tpr.geojson → tpr.pmtiles (Z4–z12)
Convert tpp.geojson → tpp.pmtiles (Z0–z14)
# Run for each layer
tippecanoe -o hex-grid.pmtiles -Z 2 -z 10 --layer=hex --force hex-grid.geojson
tippecanoe -o tpr.pmtiles      -Z 4 -z 12 --layer=tpr --coalesce-densest-as-needed --force tpr.geojson
tippecanoe -o tpp.pmtiles      -Z 0 -z 14 --layer=tpp --force tpp.geojson
3
Step 3 — S3 Private Bucket Setup
Create a fully private S3 bucket and upload the three .pmtiles files.
Create S3 bucket (block ALL public access)
Upload hex-grid.pmtiles, tpr.pmtiles, tpp.pmtiles to /tiles/
Note the bucket ARN for CloudFront policy
aws s3api create-bucket --bucket your-tiles-bucket --region us-east-1
aws s3api put-public-access-block --bucket your-tiles-bucket \
  --public-access-block-configuration \
  "BlockPublicAcls=true,IgnorePublicAcls=true,BlockPublicPolicy=true,RestrictPublicBuckets=true"

aws s3 cp hex-grid.pmtiles s3://your-tiles-bucket/tiles/
aws s3 cp tpr.pmtiles      s3://your-tiles-bucket/tiles/
aws s3 cp tpp.pmtiles      s3://your-tiles-bucket/tiles/
4
Step 4 — CloudFront Distribution + OAC
Create a CloudFront distribution with Origin Access Control so only CloudFront can read from S3. Enable Range request support (required for PMTiles).
Create OAC (Origin Access Control) in CloudFront
Create distribution → S3 origin with OAC attached
Add Range header to cache key (PMTiles needs this)
Update S3 bucket policy to allow CloudFront distribution ARN
Generate CloudFront Key Pair (for signed cookies)
Store private key in AWS SSM Parameter Store
⚠️ PMTiles uses HTTP Range requests to fetch only the tile you need from the file. Your CloudFront cache policy MUST include the Range header in the cache key, otherwise all clients get the same cached chunk.
5
Step 5 — Serverless 4: Lambda Auth Function
Deploy a Lambda endpoint (GET /tiles/auth) that issues CloudFront signed cookies. The React app calls this once on load; cookies cover all subsequent tile requests.
Scaffold Serverless 4 project
Write tiles-auth.ts Lambda handler
Set SSM env vars: CF_KEY_PAIR_ID, CF_PRIVATE_KEY, CF_DOMAIN
Deploy: sls deploy
Enable CORS + credentials on API Gateway
# serverless.yml (key parts)
functions:
  getTilesCookie:
    handler: src/tiles-auth.handler
    events:
      - httpApi:
          path: /tiles/auth
          method: GET

Step 6 — React + MapLibre Integration
Wire up the React map component with PMTiles protocol, fetch signed cookies on mount, then add all three layers with zoom-level visibility controls.
Install maplibre-gl and pmtiles
Register pmtiles:// protocol once at app entry point
Fetch /tiles/auth on app load (with credentials)
Add TPP layer (visible zoom 0–14)
Add Hex-grid layer (visible zoom 3–10)
Add TPR layer (visible zoom 5–12, color interpolation by value)
# Install
npm install maplibre-gl pmtiles

# In React component
import { Protocol } from 'pmtiles'
import maplibregl from 'maplibre-gl'

const protocol = new Protocol()
maplibregl.addProtocol('pmtiles', protocol.tile)

# Layer minzoom / maxzoom controls rendering
map.addLayer({ id: 'hex', minzoom: 3, maxzoom: 10 ... })
map.addLayer({ id: 'tpr', minzoom: 5, maxzoom: 12 ... })
map.addLayer({ id: 'tpp', minzoom: 0, maxzoom: 14 ... })
