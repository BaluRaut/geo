Honest Verdict

Recommended path: Hybrid CDN (Option 1)

Keep TPP as FlatGeobuf — it's tiny (2–5 features/country), has rich properties you need for popups, and FGB handles it perfectly.

Convert Hex grid and TPR to PMTiles — these are grid/raster-like layers with zoom semantics. tippecanoe will tile them efficiently. At zoom 5, you see clusters; at zoom 10, you see individual cells. Browser never loads 200K features at once.

Switch Leaflet → MapLibre GL — this is the uncomfortable but necessary part. MapLibre renders PMTiles with WebGL natively. Leaflet can't efficiently render 28K+ polygons at zoom 10+. Your existing UkraineLayerMap.tsx patterns translate directly to MapLibre — sources, layers, popups all work the same way.

If your data changes weekly or less — stick with Hybrid CDN. Re-tile and upload is a 5-minute CI job.
If your data changes daily or needs live queries — go PostGIS + Martin. The $70/month is worth the operational simplicity.

⚠️ Don't skip the renderer migration. The option you pick for storage doesn't fix the 200K-feature rendering problem. Whether data comes from CDN or PostGIS, rendering 200K SVG paths in the browser will lag on any machine. PMTiles + MapLibre WebGL solves both problems at once — storage efficiency and render performance.

Recommended Pipeline (Hybrid CDN)

TPP
GeoJSON → ogr2ogr → .fgb → S3 → CloudFront  (unchanged)
Hex grid
GeoJSON → tippecanoe -Z3 -z14 → .pmtiles → S3 → CloudFront + MapLibre
TPR
GeoJSON → tippecanoe -Z4 -z12 --coalesce-densest-as-needed → .pmtiles → S3 → CloudFront + MapLibre
Install tippecanoe: brew install tippecanoe  ·  PMTiles viewer to inspect output: pmtiles.io
