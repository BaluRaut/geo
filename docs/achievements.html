How We Got There — Step by Step

1
GeoJSON → FlatGeobuf
Converted all source GeoJSON files to .fgb using flatgeobuf's streaming serializer. FGB stores a Hilbert R-tree spatial index, enabling HTTP range requests to fetch only the features inside the current map viewport — no need to load an entire country's data when zoomed in. First pass: ~70% size reduction from removing JSON overhead and string repetition.
2
Flatten nested facetSummary → Alias map
The hex grid source data wrapped every property inside facetSummary.bySource.{uuid}.normalized — the UUID source key was duplicated for every feature, accounting for most of the file size. We flattened this to top-level properties and replaced the long property key names (e.g. "GrainCorn tpr - BALANCED") with short aliases (k0, k1, …). A companion alias.json (55 keys, ~3 KB) maps aliases back to human labels in the frontend. All numeric values preserved — nothing dropped.
3
Polygon → Centroid Point + shared shape template
Each hex cell is the same parallelogram shape — only the position varies. Instead of storing 4 polygon vertices per feature (80 bytes geometry), we store only the centroid point (16 bytes) and compute the average vertex offsets once per country in hex-meta.json. The frontend reconstructs the full polygon from centroid + template offsets before rendering. X-offsets vary ~1% across latitudes within a country — sub-pixel at any zoom level. Result: 98% wire size reduction on hex files.
4
TPP: Douglas-Peucker simplification
TPP files have only 2–5 features per country but massive boundary geometry — Romania TPP was 2.4 MB with 3 features. The boundaries had tens of thousands of vertices at sub-meter precision, far more than needed for display. Applied Douglas-Peucker with 0.0005° tolerance (≈ 50 m) to reduce vertex count by 90%+ while keeping boundaries visually identical at any zoom level.
5
Mapbox GL + zoom-split architecture
Switched from Leaflet SVG to Mapbox GL WebGL renderer. Below zoom 10: hex centroids displayed as cluster bubbles (Mapbox built-in clustering). At zoom ≥ 10: hex polygons reconstructed client-side from centroids + template, displayed as fills. TPR (100×100 grid): loaded per-viewport via FGB bbox range requests on moveend (debounced 350 ms) — browser never loads the full 10 K TPR cells, only what's visible. Click popup priority: hex > TPR > TPP using queryRenderedFeatures.
