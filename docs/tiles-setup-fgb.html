Architecture Decision

✅

Chose: FlatGeobuf (.fgb) + CloudFront Signed Cookies

FlatGeobuf supports HTTP range requests natively — the browser only fetches features inside the current map viewport. No tile server needed, one file per layer, streams directly from S3 via CloudFront.

ApproachEffortLarge files (10–100 MB+)Long-term
S3 Presigned URL ~1 day Whole file download each time Not ideal
CloudFront Signed Cookie ~2–3 days Range requests → viewport-only fetch ✓ Chosen

Why FlatGeobuf

📦
One file per layer
No tiling, no tippecanoe, no PMTiles complexity. Just ogr2ogr → .fgb.
🔎
Spatial index built-in
Hilbert R-tree index packed into the file. Browser fetches only bbox-matching features.
⚡
HTTP Range requests
Works with CloudFront out of the box. No server-side tile rendering needed.
🌊
Streaming in browser
flatgeobuf npm package streams features as they arrive — fast first paint.
🗺️
MapLibre compatible
Feed fetched features into a GeoJSON source — update on every map move.
💾
Handles large files
10–100 MB .fgb files work fine. Only the visible portion is ever transferred.

Step 4 — CloudFront Distribution + OAC + Restrict Viewer Access
Create a CloudFront distribution with OAC (so only CF can read S3) and set Restrict Viewer Access = Yes (so only browsers with valid signed cookies can request files).
Create Origin Access Control (OAC) for S3
Create CloudFront distribution → S3 origin with OAC
Set Restrict Viewer Access = Yes on the behavior
Add Range header to cache policy cache key (critical for FGB range requests)
Update S3 bucket policy to allow CloudFront distribution ARN
# S3 bucket policy — paste in AWS Console or via CLI
{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Principal": { "Service": "cloudfront.amazonaws.com" },
    "Action": "s3:GetObject",
    "Resource": "arn:aws:s3:::your-geo-bucket/*",
    "Condition": {
      "StringEquals": {
        "AWS:SourceArn": "arn:aws:cloudfront::ACCOUNT_ID:distribution/DIST_ID"
      }
    }
  }]
}
⚠️ Cache policy must include Range in the cache key. FlatGeobuf fetches different byte ranges of the same file for each viewport. Without this, CloudFront returns the wrong cached chunk.

// src/auth.ts
import { getSignedCookies } from '@aws-sdk/cloudfront-signer'

export const handler = async () => {
  const expiry = Math.floor(Date.now() / 1000) + 60 * 60 * 8 // 8 hrs

  const cookies = getSignedCookies({
    keyPairId:  process.env.CF_KEY_PAIR_ID!,
    privateKey: process.env.CF_PRIVATE_KEY!,
    policy: JSON.stringify({
      Statement: [{
        Resource: `https://${process.env.CF_DOMAIN}/fgb/*`,
        Condition: { DateLessThan: { 'AWS:EpochTime': expiry } }
      }]
    })
  })

  return {
    statusCode: 200,
    multiValueHeaders: {
      'Set-Cookie': [
        `CloudFront-Policy=${cookies['CloudFront-Policy']}; Path=/; Secure; SameSite=None`,
        `CloudFront-Signature=${cookies['CloudFront-Signature']}; Path=/; Secure; SameSite=None`,
        `CloudFront-Key-Pair-Id=${cookies['CloudFront-Key-Pair-Id']}; Path=/; Secure; SameSite=None`,
      ],
      'Access-Control-Allow-Origin':      [process.env.ALLOWED_ORIGIN!],
      'Access-Control-Allow-Credentials': ['true'],
    },
    body: JSON.stringify({ ok: true })
  }
}

// src/hooks/useFlatGeobuf.ts
import * as flatgeobuf from 'flatgeobuf/lib/mjs/geojson'

const CDN = 'https://d1234abcd.cloudfront.net'

export async function fetchLayer(file: string, bbox: [number,number,number,number]) {
  const [minX, minY, maxX, maxY] = bbox
  const rect = { minX, minY, maxX, maxY }

  const features: any[] = []
  const iter = flatgeobuf.deserialize(
    `${CDN}/fgb/${file}`,
    rect,
    undefined,
    { credentials: 'include' }  // sends signed cookies
  )
  for await (const f of iter) features.push(f)
  return { type: 'FeatureCollection', features }
}

// In map component — re-fetch on every move
map.on('moveend', async () => {
  const b = map.getBounds()
  const bbox = [b.getWest(), b.getSouth(), b.getEast(), b.getNorth()] as [number,number,number,number]
  const zoom = map.getZoom()

  // zoom-gated fetches
  if (zoom >= 3) (map.getSource('hex') as any).setData(await fetchLayer('hex-grid.fgb', bbox))
  if (zoom >= 5) (map.getSource('tpr') as any).setData(await fetchLayer('tpr.fgb', bbox))
                (map.getSource('tpp') as any).setData(await fetchLayer('tpp.fgb', bbox))
})
💡 Debounce the moveend handler by ~150ms to avoid firing too many range requests while the user is still dragging/zooming.
